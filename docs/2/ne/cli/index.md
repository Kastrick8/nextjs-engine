# NE-CLI — Generation 2

> [!WARNING]
> **New in 2.7 — experimental.** NE-CLI is newly introduced on the Generation 2 line. Its command surface and dashboard behavior may still change, and it may be revised, replaced or removed before a future stable release. Do not make production deployments depend on undocumented behavior.

| Command | Purpose |
|---|---|
| ne | Open the interactive dashboard |
| ne dev | Start development |
| ne build | Run the production build |
| ne start | Start production |
| ne check | Run available project checks |
| ne clean | Remove generated Engine build/cache files |
| ne help | Print command help |

Run ne help on the installed package for its exact commands. Dashboard, task routing, update/channel discovery and rollback behavior are newly introduced and evolving. See [detailed CLI guide](../../ne-cli.md) and [Error Book](../errors/error-book.md).
