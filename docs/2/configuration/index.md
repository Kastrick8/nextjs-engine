# Configuration — Generation 2

| Task | Guide |
|---|---|
| Configure external providers, HTTP defaults, macros and authentication | [EngineAPIResolver](./engine-api.md) |
| Configure compiled browser-side endpoints | [APIStatic](./api-static.md) |
| Configure page-level Engine behavior and responsive values | [Engine configuration](./engine-config.md) |

EngineAPI provider configuration and APIStatic route files are distinct inputs. The former configures requests to external APIs; the latter creates browser-executable endpoint programs.
