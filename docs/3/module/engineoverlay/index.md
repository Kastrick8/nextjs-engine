# EngineOverlay Feature Group

EngineOverlay is one module with three independently usable public primitives and shared behavior.

| Feature | Use it for | Detailed page |
|---|---|---|
| Dialog | Modal prompts, confirmations and editors | [EngineDialog](./dialog.md) |
| Drawer | Edge panels, inspectors, filters and mobile sheets | [EngineDrawer](./drawer.md) |
| Popover | Anchored menus and contextual panels | [EnginePopover](./popover.md) |
| Shared runtime | Stacking, portals, Escape, focus and scroll locking | [Shared runtime](./shared-runtime.md) |

The complete prop and schema reference remains in the [EngineOverlay module guide](../engineoverlay.md). These feature pages deepen the distinct APIs; they do not create a separate documentation page for each implementation helper.
