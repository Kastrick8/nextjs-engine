# EngineCanvas Feature Group

EngineCanvas is the entry point for the Engine's graphics scene and rendering-engine system.

| Guide | Covers |
|---|---|
| [EngineCanvas](../enginecanvas.md) | Scene lifecycle, callback mode, retained scene model and renderer registration |
| [Engine3D](../engine3d.md) | Three.js-backed 3D rendering |
| [EngineSVG](../enginesvg.md) | SVG output and ECScene import/export |

The implementation also contains Engine2D and EngineSkia renderer paths. These are documented within the Canvas reference because they are rendering backends within one graphics system, not independent top-level modules.
